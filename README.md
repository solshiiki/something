# Mind Prison Break

Минималистичная игра о когнитивных искажениях. Проект на Vite + React.

## Запуск

```bash
npm i
npm run dev
```

## Аналитика AI

По умолчанию используется мок-ответ. Чтобы получить реальный анализ:
- В Cursor/браузере с поддержкой `window.ai` — приложение воспользуется им автоматически.
- Либо укажите ключ OpenAI в `.env`:

```
VITE_OPENAI_API_KEY=sk-...
```

И соберите/запустите проект заново.
